evidence.ar.io

为保存在 Arweave 上的证据，提供永久链接。

Permanent links to evidence stored on Arweave.

每份证据文件写入 Arweave 后即不可篡改、永久存续。evidence.ar.io 把这些交易 ID 映射成易读、可分享的永久链接。

Once a piece of evidence is written to Arweave it is immutable and permanent. evidence.ar.io maps those transaction IDs to readable, shareable permanent URLs.

它是怎么工作的 · How it works

01
写入 Arweave
Write to Arweave
证据（文档、截图、哈希、合同、数据集……）上传到 Arweave，得到一个不可更改的 TxID。
Upload evidence (documents, screenshots, hashes, contracts, datasets…) to Arweave and receive an immutable TxID.
02
登记进 manifest
Register in the manifest
把 TxID 映射到一个可读路径，例如 /case-001/report.pdf，随 manifest 一起永久存在。
Map the TxID to a readable path, e.g. /case-001/report.pdf, stored permanently with the manifest.
03
通过域名访问
Access via this domain
任何人打开 https://evidence.ar.io/<路径>，网关都会解析到那份原始数据，内容永远一致。
Anyone opening https://evidence.ar.io/<path> is served the original bytes, unchanged, forever.

如何添加 · How to add evidence

目前 / Currently：请发送邮件到 tuobang@biomathematics.org，附上证据文件或其 Arweave TxID，由管理员手工登记到本域名。

Email tuobang@biomathematics.org with the evidence file or its Arweave TxID; an administrator will add it to this domain manually.

抗劫持说明 · Resilience note

manifest 可被任意站点自由引用。evidence.ar.io 背后的 manifest 本身就是一笔永久存放在 Arweave 上的交易，任何网站、任何网关都可以直接链接，无需授权。

The manifest behind evidence.ar.io is itself a permanent Arweave transaction; any website or any gateway may link to it directly, without permission.

即使 evidence.ar.io 被劫持、停用或审查，用 manifest 的 TxID 直接构造的链接依然有效，内容逐字节不变。请把下面这种备用格式一并保存或转发：

Even if evidence.ar.io is hijacked, suspended, or censored, links built directly on the manifest TxID keep serving the exact same bytes. Keep / forward the fallback form below:

当前 manifest TxID · Current manifest ID（自动读取，无需手工更新） 读取中… / reading…
